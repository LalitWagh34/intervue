# Security Policy

## Supported Versions

We release security patches and stability updates for the latest code on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The interVue team takes security seriously. If you discover a security vulnerability or vulnerability pattern in this project, please report it responsibly:

1. **Do not disclose the issue publicly** in GitHub issues, discussions, or social channels.
2. Email full vulnerability reproduction details, affected files, and proof-of-concept exploits to:
   - **lalitwagh2004@gmail.com**
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested mitigations or patches

### Response Timeline
- **Initial Response**: Within 48 hours acknowledging receipt.
- **Triage & Assessment**: Within 5 business days with an assessment of severity.
- **Fix & Disclosure**: Coordinated patch release and security advisory acknowledgment.

Thank you for helping keep interVue and its users secure!
